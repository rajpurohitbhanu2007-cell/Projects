## 🚀 Projects Overview

### 1. [DSA Project](./DSA/)
- **Topic**: Student Record Management System
- **Language**: C
- **Key Concepts**: Arrays, Linear Search, Bubble Sort, Structs
- **Modules**:
  1. Student Registration & Storage (Add, Update, Delete, Duplicate Roll check)
  2. Display & Reports (Tabular catalog, branch report, student count)
  3. Searching (Linear search by roll number and name)
  4. Sorting & Ranking (Bubble sort by roll, name, marks; merit rank list & topper)
- **Status**: ✅ Completed

### 2. [OOPs Project](./OOPs/)
- **Topic**: Library Management System
- **Language**: C++
- **Key Concepts**: Classes & Objects, Encapsulation, Inheritance, Polymorphism, Abstraction
- **Modules**:
  1. Book Management (Add, update, delete with validation)
  2. Catalog & Search (Tabular view, search by ID and title)
  3. Circulation (Issue and return books with standard borrowing periods)
  4. Late Fines & Reports (Overdue fine calculation, summary statistics)
- **Status**: ✅ Completed

### 3. [Web Development Project](./Web-Dev/)
- **Topic**: Employee Management System
- **Tech Stack**: HTML5, CSS3, Vanilla JavaScript
- **Key Concepts**: DOM Manipulation, Event Handling, CSS Grid/Flexbox, LocalStorage API
- **Modules**:
  1. Employee Registration & CRUD (Add, edit, delete with persistent storage)
  2. Directory & Department Filtering (Tabular directory, department-wise filter)
  3. Real-Time Search & Status Tracking (Instant search, status badges)
  4. Salary & Payroll Analytics (Headcount, active staff, payroll expenditure, average salary)
- **Status**: ✅ Completed
