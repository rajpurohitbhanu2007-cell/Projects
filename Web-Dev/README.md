## 📌 4-Module Division

### 1. Module 1: Employee Registration & Record Management
- **Add Employee**: Registers new staff with ID, Name, Email, Department, Designation, Salary, and Status.
- **Duplicate ID Validation**: Prevents duplicate ID assignments.
- **Update Details**: In-place edit modal for modifying staff information.
- **Delete Employee**: Deletes employee records with confirmation.
- **Local Persistence**: Saves all records to browser `localStorage` so data persists after refreshing or reopening the browser.

### 2. Module 2: Directory & Department Filtering
- **Tabular Directory**: Responsive, styled table displaying complete staff records.
- **Department Filter**: Dropdown to filter records by department (Engineering, Product, Marketing, Sales, Human Resources).
- **Responsive Layout**: Adapts seamlessly to both desktop and mobile viewports.

### 3. Module 3: Real-Time Search & Status Tracking
- **Live Search**: Instant real-time filtering as you type across Employee Name, Designation, Email, or ID.
- **Status Management**: Visual status badges for **Active** (green), **On Leave** (yellow), and **Inactive** (red).

### 4. Module 4: Salary & Payroll Analytics
- **Total Staff Headcount**: Real-time counter of total employees.
- **Active Staff Counter**: Tracks currently active staff members.
- **Monthly Payroll Expenditure**: Sums total salary expenses across the organization.
- **Average Salary**: Computes average salary per employee dynamically.

## 🛠️ Tech Stack
- **HTML5**: Semantic tags, accessible form controls, clean structure.
- **CSS3**: Modern CSS variables, Flexbox, CSS Grid, status badges, responsive breakpoints, smooth modal animations.
- **Vanilla JavaScript (ES6+)**: DOM manipulation, filter/search logic, array methods (`map`, `filter`, `reduce`), `localStorage` API.

## 🚀 How to Run the Website

### Simple Direct Run:
1. Navigate to the `Web-Dev` folder.
2. Double-click **`index.html`** to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).

### With VS Code Live Server (Optional):
Right-click `index.html` inside VS Code and select **"Open with Live Server"**.
